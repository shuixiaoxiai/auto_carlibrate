# 第八步：完整测试人员工作流

状态：**已完成**

完成日期：2026-07-30

## 手动方向记录

桌面界面新增固定的“手动方向记录”操作区：

- 手动选择正前、右前、正右、右后、正后、左后、正左、左前。
- 每个方向由测试人员点击“开始记录”和“手动结束”。
- 实际解锁出现后仍继续采集，直到测试人员手动结束。
- 手动输入闭锁距离、解锁距离和本方向步速。
- 状态提示区依次显示等待闭锁、等待解锁、已解锁继续记录、数据源结束和错误。
- 事件或距离缺少时仍可结束，保存为“不完整方向”；已输入的单个距离不会丢失。
- 支持“重录所选方向”，删除旧记录前二次确认。
- 支持“完成本次测试并保存”，显示完整/不完整方向数量。

`ManualCaptureCoordinator` 使用锁隔离 Qt 操作线程与 `CaptureWorker` 接收线程。CAN 回调
只写会话状态；界面以 100 ms 周期读取不可变快照并刷新当前图，绘图不会阻塞接收。

## Mock 实时采集

`MemoryCanSource` 和 `ManualMockProvider` 把确定性 Mock CAN 帧按当前所选方向送入正式
采集线程、正式协议解码器和正式会话状态机。Mock 只提供原始帧，不直接注入 RSSI 或
事件结果。

启动手动 Mock 新项目：

```bash
python3 run_app.py gui \
  --manual-mock \
  --project-name "八方向手动标定"
```

默认 10 倍速播放单方向 24 秒数据；`--replay-speed` 可以调整，`0` 表示最快。

## 项目新建、保存和打开

界面工具栏提供“新建 / 打开 / 保存”：

- SQLite 项目库默认位于用户数据目录，也可以通过 `--database` 指定。
- 每个方向的原始帧实时追加到独立 JSONL 附件，数据库只保存路径。
- 保存项目时同时保存原始/当前云推 HEX、方向记录、距离、步速、参数历史和分析结果。
- 打开项目后从 JSONL 重建 `RssiSample`，恢复当前 What-if 参数、8 张图和统计。
- 30 秒周期保存异常恢复快照；每个方向结束后立即刷新恢复快照。
- 切换项目或关闭窗口时如有未保存更改，会提供保存、放弃和取消。
- 采集中禁止新建或打开项目；关闭时必须确认并将当前已有数据保存为完整或不完整方向。

零采样的不完整方向也可以保存和重开，不会因缺少时间范围导致整个项目打开失败。

## 自动验收

无 Qt 的并发/存储测试覆盖：

- 采集线程与手动结束并发。
- 完整方向保留解锁后的样本。
- 单个距离和缺失事件的不完整保存。
- 原始 JSONL、SQLite、参数修改及重开结果一致。

真实 Qt 控件工作流：

```bash
python3 tools/manual_ui_smoke.py \
  --width 1100 \
  --height 720
```

该脚本通过窗口操作路径完成 8 个方向：

```text
选择方向
  → 开始记录
  → 接收闭锁/解锁
  → 输入两个距离
  → 手动结束
  → 下一方向
  → 完成本次测试并保存
  → 关闭数据库后重新打开
```
