# 第七步：Windows 原生界面

状态：**已完成**

完成日期：2026-07-30

## 技术实现

- 桌面框架：`PySide6==6.7.3`。
- 图表：`pyqtgraph==0.13.7`。
- 核心状态：`CalibrationUiState`，只持有不可变方向数据、当前云推文档和同一次
  `RecomputeResult`。
- 图表绘制不参与 CAN 接收；参数修改使用 55 ms 防抖，曲线数据与事件标记分开更新。
- Qt 入口采用延迟导入，核心命令和单元测试不要求创建 GUI 运行时。

## What-if 参数区

顶部参数模块已实现：

- 5 节点解锁和闭锁阈值。
- 源云推中存在的 `mstUnlock`、`quickLock`、`quickUnlock`、`mstThanSlave` 和
  `bevelAngle`。
- 云推 HEX 解码、修改后编码并复制。
- 一键还原本次解码参数。
- 隐藏/显示；在图表顶部和全部图表底部均可重新显示。
- 闭锁和解锁优秀率、优/良/差数量、良方向和差/未触发方向。

阈值或策略改变时，事件线、触发节点、实线瞬时 RSSI、距离、各方向等级和两套汇总
来自同一个结果对象，不存在图表新而汇总旧的缓存路径。

## 八方向图表

界面纵向排列正前、右前、正右、右后、正后、左后、正左、左前 8 个方向：

- 每图 5 条节点 RSSI 曲线，横轴每 2 秒一个主刻度。
- 单图最小绘图区高度 430 px，参数隐藏后使用完整页面宽度。
- 实线表示条件开始满足，旁边文字只显示 `闭(主)`、`解(前)` 等。
- 虚线表示动作时刻，参数变化后实线和虚线同时移动。
- 图表背景按距离时间轴显示绿色优、黄色良、红色差。
- 图下方分别显示闭锁和解锁的策略、实线/虚线时刻、动作距离与等级。
- 5 节点瞬时 RSSI、相对当前阈值的 dB 差和条件时刻前 0.5 秒变化率均取实线时刻。
- 每个方向可以单独修改实际闭锁距离、实际解锁距离和步速，随后同步重算图表和汇总。

## 启动和验收

无需生成外部文件即可启动确定性 Mock 八方向界面：

```bash
python3 run_app.py gui
```

也可以打开既有 Mock JSONL：

```bash
python3 run_app.py gui \
  --input mock_data/eight_directions.jsonl \
  --manifest mock_data/eight_directions.manifest.json
```

端到端冒烟测试：

```bash
python3 tools/ui_smoke.py \
  --width 1100 \
  --height 720 \
  --max-refresh-ms 200
```

该测试会真实创建 Qt 窗口、绘制 8 张图和 40 条曲线，将 5 个闭锁阈值改为
`-100 dBm`，确认 8 个方向及闭锁汇总全部变为 `差（未触发）`，并把防抖、控件更新和
实际绘制计入刷新时间。

## 验收证据
