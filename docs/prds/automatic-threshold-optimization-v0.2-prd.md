# 自动阈值优化 v0.2 - 实现与 Windows 验收基线

文档状态：Implemented

版本：0.2

实现版本：BLE Calibration 0.10.1

## 1. 用户目标

测试人员完成方向采集或打开历史项目后，通过一次全局自动优化，获得一组可解释、可预览、
可还原的 What-if 参数。应用不得自动向车辆或云端写入参数。

## 2. 已冻结业务规则

- 所有启用节点满足 `U_i - L_i >= 3 dB`；原本成对禁用的零阈值保持禁用。
- 非零阈值搜索范围为当前值 `±10 dB`，整数步长 `1 dB`，优化器不生成零值。
- 每个完整原始“方向 + 组”独立参与评分，均值曲线不进入优化器。
- 闭锁和解锁优秀率分别不得低于 `75%`。
- 不允许差或未触发。
- 每个完整方向组必须满足闭锁距离大于解锁距离。
- 当前解锁距离不低于 `1m` 的组不得新增 `<1m` 解锁；原本低于 `1m` 的组不得继续变近。
- 质量和安全约束满足后，尽量扩大主节点 `U_main-L_main`。
- 同等质量下先最大化最小解锁距离，再偏向更远的闭锁距离；无法满足时展示最保守失败预览，
  但禁止应用。
- 基础阈值优先；达到搜索平台后才允许逐个尝试单一附加策略。

## 3. 完整方向组

一组优化输入必须同时包含：

- 完整五节点 RSSI 序列；
- 实车闭锁和解锁动作时刻；
- 实测闭锁和解锁距离；
- 有效步速；
- 当前云推参数。

没有任何完整方向组时禁用“自动优化”。部分方向或组缺失时允许运行，但明确标记数据覆盖不足；
不完整组会被列出并跳过。

## 4. 方向分块

| 方向 | 主动搜索节点 |
| --- | --- |
| 正前 | 主、前 |
| 右前 | 主、前、右 |
| 正右 | 主、右 |
| 右后 | 主、右、后 |
| 正后 | 主、后 |
| 左后 | 主、左、后 |
| 正左 | 主、左 |
| 左前 | 主、左、前 |

从节点先搜索，主节点后搜索。调整从节点时只重放物理相关方向；调整主节点时重放全部方向。
未被主动搜索的节点阈值保持不变，但正式 `StrategyEngine` 重放始终保留五节点，以遵守闭锁
AND 和解锁 OR 规则。局部候选接受前必须再执行全部完整方向组复核。

## 5. 确定性搜索

实现使用无外部优化依赖的受约束分块坐标搜索：

1. 对当前参数建立完整基线。
2. 暂时关闭附加策略，优先搜索基础阈值。
3. 按当前最差方向确定从节点顺序，扫描单阈值、节点参数对和平移/扩间隔候选。
4. 搜索主节点并执行相关节点 `±1 dB` 联合校验。
5. 只有全局字典序改善且完整重放验证通过才接受候选。
6. 基础阈值不合格时，逐个尝试主节点单独解锁、快速闭锁、快速解锁、主强于从、斜角策略；
   任一候选只启用一种策略。
7. 最终结果执行所有单阈值 `±1 dB` 稳定性检查。

搜索为确定性任务；相同数据、参数和配置得到相同推荐。候选达到预算仍无合格方案时，文案为
“在当前范围和候选评估上限内未找到合格方案”，不声称数学上的全局无解。

## 6. 用户流程

1. 完成采集、打开历史项目或解码当前云推参数。
2. 点击 What-if 参数区的“自动优化”。
3. 检查方向数、完整组数、当前优秀率和固定安全规则。
4. 点击“开始优化”；任务在后台运行，可以取消。
5. 查看当前/推荐优秀率、十个阈值、主节点间隔、每组距离/评级/触发路径和稳定性。
6. 合格方案可以点击“应用到 What-if”；失败预览的应用按钮保持禁用。
7. 检查八方向图表后，测试人员可手动“编码并复制”，再进行实车复验。
8. 需要时使用“一键还原”恢复本次解码参数。

优化期间如果参数或方向数据发生变化，完成结果会被判定为过期，禁止应用并要求重新运行。

## 7. 自动化验收

核心回归：

```bash
python -m unittest discover -s tests -v
```

完整离屏用户流程：

```bash
python tools/optimization_ui_smoke.py --timeout-seconds 60
```

验收脚本必须证明：

- 自动优化按钮和预检页面可用；
- 后台搜索完成且 UI 未阻塞；
- 推荐满足阈值差、优秀率、无差、距离顺序和 `<1m` 保护；
- 合格结果可应用到 What-if；
- 参数 HEX 发生对应变化；
- 没有车辆写入动作。

## 8. Windows 人工验收

- 在 Windows 10/11 64 位环境按 `packaging/windows/README.md` 构建或直接从源码运行。
- 使用 Mock 项目走完第 6 节流程，确认结果页能应用并可一键还原。
- 使用不完整项目确认自动优化按钮禁用且提示原因准确。
- 运行中点击取消，确认参数不变。
- 构造无法满足要求的数据，确认失败预览可查看但“应用到 What-if”不可点击。
- 最终使用真实八方向、多组数据复验推荐，并由测试人员人工编码复制；应用不得写车。
